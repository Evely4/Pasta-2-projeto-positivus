# 🚀 Teste Técnico: Frontend Developer & Designer @ Asimov Academy

Landing Page de alta performance para o curso de Python + IA, focada em estética moderna, usabilidade e conversão.

### 🧠 Relato de Uso de IA (Processo Seletivo)
- **Ferramentas:** Utilizei o Gemini (Google) como copiloto para otimização de código e estruturação de design.
- **Etapas de auxílio:** A IA auxiliou na geração da estrutura base HTML/CSS e na implementação da lógica de menu responsivo (Offcanvas).
- **Ajustes Manuais:** Refinei manualmente a hierarquia visual do menu desktop (títulos e subtítulos), as micro-interações dos botões e a adaptação fina para dispositivos móveis.
- **Motivação:** Os ajustes manuais garantiram que a experiência de usuário (UX) fosse intuitiva, mantendo os pesos visuais fiéis à identidade da Asimov e garantindo acesso rápido à Área do Aluno.

---

## 🎨 Conceito de Design
O projeto segue a linha "Premium Dark Mode", com inspirações em interfaces como **Linear** e **Antimetal**, utilizando a paleta oficial da **Asimov Academy** (Carbono e Verde Neon #B9FF66).

## ✨ Diferenciais Implementados
- **Menu Estratégico:** Navegação desktop com títulos e subtítulos para melhor hierarquia.
- **Acesso Facilitado:** Botão de login ("Área do Aluno") integrado de forma nativa no header e menu mobile.
- **Responsividade Completa:** Menu hambúrguer com painel lateral (gaveta) para excelente navegação em dispositivos móveis.
- **Floating Support:** Botão de suporte flutuante para aumentar a confiança e conversão.
- **Code Simulator:** Card visual de código com destaque de sintaxe para identificação com o público técnico.

## 🛠️ Tecnologias
- HTML5 Semântico / CSS3 Moderno / Bootstrap 5 / Google Fonts (Space Grotesk)
