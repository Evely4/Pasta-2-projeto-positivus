# Pasta-2-projeto-positivus

# 🚀 Teste Técnico: Frontend Developer & Designer @ Asimov Academy

Landing Page de alta conversão para o curso de Python + IA, focada em estética moderna e performance.

### 🧠 Relato de Uso de IA (Processo Seletivo)
- **Ferramentas:** Utilizei o Gemini (Google) para auxílio na codificação e estruturação do design.
- **Etapas de auxílio:** A IA ajudou na geração da estrutura base HTML/CSS e na lógica de micro-interações.
- **Ajustes Manuais:** Refinei manualmente a hierarquia do menu (títulos/subtítulos) e o botão de suporte.
- **Motivação:** Ajustes feitos para evitar um visual "artificial", garantindo espaçamentos elegantes e UX fluida.

---

## 🎨 Conceito e Direção de Arte
O design foi inspirado em referências "Premium Dark Mode" como **Linear**, **Antimetal** e na própria identidade visual da **Asimov Academy** (Verde Neon #B9FF66). O foco foi criar um ambiente tecnológico que utiliza *Glassmorphism* e *Glow Effects* para destacar o conteúdo.

## ✨ Diferenciais do Projeto
- **Menu Elaborado:** Estrutura com Títulos e Subtítulos para melhor hierarquia de informação.
- **Dual-CTA Strategy:** Pontos de conversão estratégicos no Header e no Hero.
- **Floating Support:** Inclusão de botão flutuante de dúvidas para aumentar a confiança do usuário.
- **Code Simulator:** Card de código estilizado com realce de sintaxe para identificação com o público dev.

## 🛠️ Tecnologias
- HTML5 Semântico, CSS3 (Variáveis e Grid), Bootstrap 5 e Google Fonts.
